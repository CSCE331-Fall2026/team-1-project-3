# Sprint Goals

*Instructions: For each sprint, write a one or two sentence goal plus the single demoable outcome that proves the sprint succeeded. Keep in mind that you will conduct user studies after sprints 1 and 2 to get feedback to inform future development, so define MVP goals to be most helpful for that. The sprint 3 MVP should be your final product.*

## Sprint 1
**Goal:** The team will integrate the locally hosted GUI into a web application that maintains connection to the database and has minimal changes to the backend. Additionally, the team will add the basics of the interfaces for customer and kitchen staff.

**Outcome:** A successful demo will have the application on the web with the user able to do everything they could do in the previous app as well as switch to customer and kitchen staff view.

## Sprint 2
**Goal:** The team will fully implement the new features for all interfaces (cashier, manager, customer, and kitchen staff).

**Outcome:** A successful demo will have all previous features as well as allowing the user to order from the customer's view and see all orders and stock in the kitchen staff's view.

## Sprint 3
**Goal:** The team will implement a novel feature and authenticated logins via Google authentication.

**Outcome:** A successful demo will have all previous features as well as a third party authentication for each type of user and a recommendation/most popular feature.
