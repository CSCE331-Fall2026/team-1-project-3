# Team 1's Style Guide

## Guideline for character spacing.
- Space before and after operation symbols (ex: 1 + 1)
- Space after commas (for like parameters and such)

## Guideline for blank lines.
- Use to separate functions/blocks of code
- One line of space

## Guideline for indentation.
- 4 space indentation/tab

## Guideline for variable declaration placement and alignment.
- Normal/one space before and after the equal sign (no indentation).
- camelCase for Java and React files
- snake_case for SQL
- Group similar variable types together in class variable declaration.

## Guideline for case statement alignment.
- Camel casing.

## Guideline for comment layout.
- One empty line between what is being commented on on both sides
- Javadoc documentation before every function
